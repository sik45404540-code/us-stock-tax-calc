## 계산 규칙

### 양도세 (2026년 귀속)
근거: 소득세법 제94·98·102·103조, 지방세법 제103조의3, 국세청 「2026년 신고안내 – 해외주식과 세금」.

1. 양도소득금액 = 실현이익 − 실현손실 − 필요경비
2. 과세표준 = 양도소득금액 − 기본공제 250만 원(국내·해외 합산, 연 1회)
3. 산출세액 = 과세표준 × 20% + 지방소득세 10% → 실효 22%
4. 손실은 그해 안에서만 통산(이월 없음)
5. 역산: 필요 손실 = `max(0, 순이익 − 250만)`, 주수 = `ceil(필요손실 ÷ 주당손실)`
6. 연말 마감은 결제일(T+1). 2026년 안전선 12월 29일(화). 12월 30일(수) 미국 체결분은 12월 31일(목)이 한국거래소 연말 휴장일이라 **2027년 귀속 가능성이 높아 비권장**
7. **RIA(국내시장 복귀계좌) 과세특례**(조세특례제한법 제91조의26, 2026.3.31. '환율안정 3법' 통과)
   - 2025.12.23. 이전 보유 국외상장주식을 RIA 계좌로 2026.12.31.까지 매도 → 양도소득금액 × 매도 시점별 공제율(1.1~5.31. 100% / 6.1~7.31. 80% / 8.1~12.31. 50%)
   - 납입한도 5,000만 원(금융회사 합계), 납입일부터 1년 내 인출 시 추징 + 이자상당가산액
   - 기본값은 적용 안 함(0원)이라 기존 계산 결과에 영향이 없고, 금액·매도 시점을 넣으면 양도소득금액에서 뺀 뒤 기본공제를 적용
   - 환헤지 파생상품 매입액 5%(최대 500만 원) 공제는 별도 특례로 계산에 넣지 않고 안내만 함

### 배당·금융소득
근거: 소득세법 제14조③6호·제17조·제55조·제57조·제62조·제129조, 한미 조세조약 제12조, 국민건강보험법 시행규칙 별표 1의2.

- 국내 배당·이자: 소득세 14% + 지방소득세 1.4% = **15.4%**
- **배당가산(Gross-up) 10%**(2024.1.1. 이후 지급분, 2027년 지급분부터 11%) + **배당세액공제**
  - 대상: 내국법인 주식 배당만. 해외주식 배당·국내 상장 ETF·리츠·펀드 분배금은 제외
  - 가산 대상 금액 = 2,000만 원 초과분에 들어간 국내 배당(기준금액은 이자 → 가산 제외 배당 → 가산 대상 배당 순으로 채움)
  - ①에 가산액을 더해 산출하고, 배당세액공제 = min(가산액, ① − ②)를 세액에서 차감
  - 예시: 국내 배당 3,000만 + 근로소득금액 5,000만(소득공제 0) → 가산 100만, ① 1,168만 · ② 1,044만 → 국세 **1,068만 원**, 지방세 포함 1,174.8만, 원천징수 462만 차감 시 5월 추가 납부 **712.8만 원**
- 미국 배당: 현지 **15%** 원천징수. 국내 세율(14%)보다 높아 국내 추가 징수 없음(소득세법 제129조④)
- 금융소득 2,000만 원 초과 시 비교과세 **max(①, ②)**
  - ① 2,000만×14% + (초과 금융소득 + 다른 종합소득금액 − 소득공제) × 기본세율
  - ② 금융소득×14% + (다른 종합소득금액 − 소득공제) × 기본세율
- 외국납부세액공제 한도 = 산출세액 × 국외소득 ÷ 종합소득금액
- 2026년 기본세율 8구간(6·15·24·35·38·40·42·45%) + 지방소득세 10%
- 건강보험 피부양자: 합산소득 2,000만 원(재산 5.4억/9억 원 구간), 금융소득 1,000만 원 초과 시 전액 합산

### ISA
근거: 조세특례제한법 제91조의18.

- 비과세: 일반형 200만 원, 서민·농어민형 400만 원 / 초과분 **9.9%** 분리과세
- 납입한도 연 2,000만 원, 총 1억 원, 의무가입 3년
- 계좌 내 손익통산 → 순수익 기준 과세(일반계좌 15.4%는 상품별 과세)
- 만기 후 60일 내 연금계좌 전환: 전환금액 10%, 최대 300만 원 세액공제

### 증권사 CSV 자동 집계 (`CSV 불러오기` 탭)
증권사 앱에서 내려받은 해외주식 실현손익 파일을 그대로 올리면 실현이익·실현손실·필요경비를 나눠 계산하고, `세액 계산` 탭 입력값을 한 번에 채웁니다.

- **인코딩 자동 판별**: UTF-8(BOM) → 실패하거나 깨지면 EUC-KR/CP949로 재디코딩. 엑셀이 저장한 UTF-16LE/BOM도 처리
- **구분자 자동 판별**: 쉼표·탭·세미콜론·파이프 (줄마다 같은 개수가 나오는 쪽을 고름)
- **머리글 자동 탐색**: 맨 위 `조회기간` 안내 줄·빈 줄을 건너뛰고 컬럼 이름 점수로 머리글 줄을 찾음. 맨 아래 `합계` 줄은 집계에서 제외
- **컬럼 자동 매핑**: `종목명/종목/티커`, `실현손익/양도손익/매매손익/손익금액`, `매도금액/양도가액`, `매수금액/취득가액`, `수수료/제비용`, `수량/매도수량`과 영문 머리글. `평가손익`·`현재가`는 실현손익으로 쓰지 않음. 못 찾거나 틀리면 드롭다운으로 직접 지정
- **숫자 파싱**: `1,234,567` `-500,000` `(500,000)` `△500,000` `1,234-` `$1,200` `1,234원`
- **통화**: 머리글·값에 `$`/`USD`/`달러`가 있으면 달러로 보고 환율 입력칸으로 원화 환산(행별 환율 컬럼이 있으면 그 값 우선). 원화 컬럼만 있으면 환율칸은 숨김
- **수수료 처리**: 기본은 필요경비로 더하고, 손익에 이미 반영된 파일이면 체크를 풀어 이중 차감을 막음
- 파일은 `FileReader`(arrayBuffer)로 브라우저 안에서만 읽고 전송·저장하지 않음
- **증권사별 CSV 받는 법**: 업로드 영역 위 `? 증권사별 CSV 받는 법` 토글(`<details>`, 기본 닫힘)을 누르면 키움·신한·삼성·NH·토스·미래에셋 6개 증권사 탭이 펼쳐집니다. 메뉴 경로·HTS 조회 번호(`[3141]` `[7880]` `[6067]` `[9467]` `[9468]`)와 `CSV(쉼표로 분리)` 저장 순서를 안내합니다. 자바스크립트가 없어도 토글은 열리고 닫히며, 390px에서는 3열×2줄로 접혀 이름이 잘리지 않습니다

### 증여세 (2026년 증여분)
근거: 상속세 및 증여세법 제53조·제53조의2·제55조·제56조·제57조·제58조·제69조, 소득세법 제97조의2, 국세청 증여세 안내.

1. 과세가액 = 증여재산 + 같은 증여자에게서 10년 내 받은 재산(합계 1천만 원 이상일 때만 합산, 제47조②)
   - 관계별 공제: 배우자 6억 · 직계존속 5천만(미성년 2천만) · 직계비속 5천만 · 기타친족 1천만 · 타인 0원
   - 기타친족 범위는 **2025.3.14. 시행 현행 기준 4촌 이내 혈족·3촌 이내 인척**(종전 6촌·4촌은 2025.3.13. 이전 증여분)
2. 공제 = 관계별 10년 누계 한도 − 이미 쓴 금액 + 혼인·출산 1억(직계존속만, 혼인+출산 통합 1억)
3. 과세표준 = max(0, 과세가액 − 공제) → **50만 원 미만이면 과세최저한으로 0원**(제55조②)
4. 산출세액 = 과세표준 × 세율 − 누진공제 (10% / 20%−1천만 / 30%−6천만 / 40%−1.6억 / 50%−4.6억)
5. 세대생략 할증 = 산출세액 × 30%(미성년자이고 증여재산가액 20억 초과 시 40%, 제57조)
6. 납부세액 = 산출세액 + 할증 − 기납부세액, 그 뒤 **신고세액공제 3%**(제69조, 기본 ON)
7. 배우자 증여 비교: A 바로 매도 = (평가액 − 원취득가 − 필요경비 − 250만) × 22%, B 증여 후 1년 초과 매도 = 증여세만(매도가=증여평가액이면 양도차익 0원). 1년 내 매도 시 이월과세로 취득가액이 원래대로 돌아가고 낸 증여세는 필요경비

### 연금저축·IRP 세액공제 (2026년 귀속)
근거: 소득세법 제59조의3(연금계좌세액공제), 시행령 제40조의2(연금계좌 등)·제118조의2(전환 절차)·제118조의3(한도 초과분 전환 특례), 지방세법 제103조의3, 국세청 「소득·세액 공제신고서 작성방법」(2026.3.20. 개정).

1. 연금저축 인정액 = `min(연금저축 납입액, 600만 원)`
2. IRP 인정액 = `min(IRP 납입액, 900만 원 − 연금저축 인정액)` (합산 900만 원)
3. ISA 전환: 전환금액은 연금계좌 납입액에 포함되므로 **900만 원의 남은 자리를 먼저 채우고**, 남는 금액은 추가 한도 `min(전환금액 × 10%, 300만 원)` 안에서 인정 → 공제 대상 최대 1,200만 원
4. 공제율: 총급여 5,500만 원 이하(종합소득금액 4,500만 원 이하) **15%**, 초과 **12%**
5. 소득세 공제 = `floor(인정액 × 공제율)`, 지방소득세 = 소득세 공제액의 10%(1.5%·1.2% 상당) → 합계 16.5%·13.2%
6. 납입한도 점검: 연금저축 + IRP > 1,800만 원이면 경고. **ISA 전환금액은 1,800만 원 한도와 별도**(시행령 제40조의2 ②1호 가목·나목 합산)
7. 공제 한도 초과분은 빨간 경고 대신 중립 안내 — 과세이연 유지 + 다음 해 이후 전환 신청(시행령 제118조의3) 가능
8. 2026년 12월 31일(목) 입금분까지 2026년 귀속. 2027년 납입분부터 적용되는 청년(15~34세) 퇴직연금 15% 단일 적용은 2026년 세제개편안(국회 심사)이라 계산에 넣지 않음

### 연말정산 환급금 (2026년 귀속)

### 수수료
- 매수 환전 = 투자금 × 스프레드 × (1 − 우대율), 매수 수수료 = 환전금액 × 수수료율
- 매도 수수료 = 매도금액 × 수수료율, 매도 환전 = (매도금 − 수수료) × 스프레드 × (1 − 우대율)
- 손익분기 수익률 = `투자금 ÷ (순투자금 × (1 − 수수료율) × (1 − 유효 스프레드)) − 1`

## 배포

빌드 단계가 없으므로 저장소 루트를 그대로 정적 배포합니다.

- Cloudflare Pages: 프로젝트 `us-stock-tax-calc`, 프레임워크 없음, 빌드 명령 없음, 출력 디렉터리 `/`
- 커스텀 도메인 `taxmoa.com` / `www.taxmoa.com` 연결
- 자산 캐시: `assets/style.css?v=7`·`assets/*.js?v=N` — 파일을 고치면 N을 올려야 방문자 브라우저에 바로 반영됩니다.
- **주소 표기**: Cloudflare Pages는 `dividend.html`을 `/dividend`로 308 리다이렉트합니다. 그래서 canonical·og:url·사이트맵·내부 링크는 확장자 없는 주소(`https://taxmoa.com/dividend`)를 씁니다.

## 알아 둘 것

- 원 단위 계산이라 홈택스와 1~2원 차이가 날 수 있습니다.
- 입력값은 브라우저에서만 처리됩니다. 양도세 계산기·장부는 `localStorage`에만 저장됩니다.
- 단순화한 부분(배당가산·배당세액공제, 고배당기업 분리과세 특례, ISA 중도해지 추징, 수수료 최소액)은 각 페이지 해설에 명시했습니다.
- 계산 결과는 참고용이며 세무·투자 자문이 아닙니다.
