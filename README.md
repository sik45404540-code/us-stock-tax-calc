그 아래에 **1,500자 이상 해설**(계산 공식 4단계, 기본공제, 손익통산, 결제일 T+1, 환율, 12월 체크리스트, 신고 일정, 실수 3가지)과 **FAQ 6문항**이 있고, `WebApplication` + `FAQPage` JSON-LD, OG 태그, `robots.txt`, `sitemap.xml`, 개인정보처리방침(`privacy.html`)을 포함합니다.

## 계산 규칙 (2026년 귀속)

근거: 소득세법 제94조·제98조·제102조·제103조, 지방세법 제103조의3, 국세청 「2026년 신고안내 – 해외주식과 세금(개인투자자용)」.

1. **양도소득금액** = 실현이익 − 실현손실 − 필요경비(수수료 등)
2. **과세표준** = 양도소득금액 − 기본공제 **250만 원**(국내·해외 합산, 연 1회)
3. **산출세액** = 과세표준 × 20% (원 단위 절사) + 지방소득세 = 산출세액의 10% → 실효 **22%**
4. 순이익 250만 원 이하 → **납부 세액 0원**
5. 손실은 **그해 안에서만** 통산, 이월 없음 → 필요한 손실보다 더 팔아도 세금은 더 줄지 않음
6. **역산**: 필요 손실 = `max(0, 순이익 − 250만원)`, 주수 = `ceil(필요손실 ÷ 주당손실)`, 보유 수량 상한
7. **연말 마감**: 양도 시기 = 결제일(소득세법 제98조). 미국 주식 T+1 → 2026-12-30(수) 체결분이 12-31 결제(2026년 귀속), 증권사 국내 결제 처리를 감안한 **안전선 12-29(화)**. 12-31(목) 체결분은 2027-01-04 결제 → 2027년 귀속

## 배포

빌드 단계가 없으므로 저장소 루트를 그대로 정적 배포합니다.

- Cloudflare Pages: 프로젝트 `us-stock-tax-calc`, 프레임워크 없음, 빌드 명령 없음, 출력 디렉터리 `/`
- GitHub Pages: 저장소 Settings → Pages → Deploy from a branch → `main` / `/` (현재 임시 공개용)
- 커스텀 도메인은 추후 애드센스 신청 시 연결
- 자산 캐시: `index.html`의 `assets/style.css?v=N`·`assets/app.js?v=N` — 파일을 고치면 N을 올려야 방문자 브라우저에 바로 반영됩니다.
